# sgl-time-domain-imaging

**Time-Domain Imaging of Rotating, Cloud-Covered Exoplanets with the Solar
Gravitational Lens: An Open Inversion Framework, a Cloud-Limited Fidelity
Ceiling, and Mission Cadence Requirements**

Sanskar Sontakke (Independent Researcher)
[ORCID 0009-0008-4531-5707](https://orcid.org/0009-0008-4531-5707) · sanskarsontakke@gmail.com

This repository contains the complete paper, simulation code, and data
products. Every number, figure, and table in the manuscript regenerates
from the code in `src/` (fixed seeds; the full revised suite is a few
core-hours across four parallel streams, not 40 core-minutes).

The revision withdrew several earlier claims rather than restating them with new
numbers (in-flight ephemeris refinement, the "93.75% information retained"

## Quickstart

```bash
pip install -r requirements.txt
cd src
python3 run_experiments.py setup          # caches operators (~10 s)
python3 run_experiments.py validation     # reproduces published benchmarks
python3 make_figures.py                   # figures from shipped results/
```

Full regeneration of all experiments (run from `src/`; every command loops its
seeds internally, and every one writes a checkpoint under
`results/parts/*.npz`, so an interrupted suite resumes rather than restarts):

```bash
cd src
python3 run_experiments.py setup          # cached operators + sigma_cl audit
python3 run_experiments.py quadrature     # 3-node vs 16-node exposure check
python3 run_experiments.py ledger         # both resource arms, analytic only
python3 run_experiments.py validation     # reproduces published benchmarks

# cloud-cover sweep: one command per nominal fraction (0..4 = fc 0, .25, .40, .55, .70)
for i in 0 1 2 3 4; do python3 run_experiments.py clouds $i; done

# cadence law: arm = photons (arm A) | wallclock (arm B), config 0..4 = Mp 4..64
for arm in photons wallclock; do
  for i in 0 1 2 3 4; do python3 run_experiments.py cadence $arm $i; done
  # causal controls on the same campaigns
  for i in 0 1 2 3 4; do
    python3 run_experiments.py cadence_control $arm $i cf
    python3 run_experiments.py cadence_control $arm $i iid
  done
done

# estimator ablation + robustness suite (no arguments)
python3 run_experiments.py components
python3 run_experiments.py robust_debias  # debiasing mis-specification
python3 run_experiments.py robust_clim    # structured climatology variants
python3 run_experiments.py robust_geom    # pole tilt + assumed phase
python3 run_experiments.py robust_prof    # profile-likelihood grid
python3 run_experiments.py resolution     # real-harmonic r(l)
python3 run_experiments.py nulls_cloud    # shared 40-member cloud-only null
python3 run_experiments.py nulls          # d' vs both nulls
python3 run_experiments.py systematics    # coronal drift / streamer injection
python3 run_experiments.py static_ref     # frozen-planet ideal-data reference
python3 run_experiments.py latband        # latitude bands + polar restricted r
python3 run_experiments.py diagnostics    # deflation / information diagnostics
python3 run_experiments.py precision      # numerical precision audit

# regularization and assumed-amplitude sweeps
for i in 0 3; do
  python3 run_experiments.py lam_sweep $i
  python3 run_experiments.py lam_ext $i
  python3 run_experiments.py lam_res $i
done
python3 run_experiments.py robust_weather corr8    # also: corr20 u3 u12 tau2 tau8
python3 run_experiments.py sigma_sens
python3 run_experiments.py sigma_sens_est
for i in 0 3; do python3 run_experiments.py robust_morph $i; done

# assemble archives + audit.json, then the derived products
python3 run_experiments.py merge
python3 targets.py
python3 make_figures.py

cd ..    # the demo payloads below run from the repository root
python3 src/make_app_maps.py
python3 src/make_app_data.py
python3 src/make_app_code.py
python3 src/make_app_figures.py   # mirrors paper/figures -> web/public/figures

# the manuscript and its byte mirror
cd paper && latexmk -pdf -interaction=nonstopmode main.tex && cd ..
python3 src/make_app_docs.py      # mirrors paper/main.pdf into web/public/docs/
```

Seeds: truth map 7 · campaign geometry 2026 · realizations 11–20 (cadence arm:
11–16) · cloud-climatology probes 999. The regularization weight
`LAM_GLS = 3e-3` is a hardcoded constant inherited from the approximate-deflation baseline, not a value tuned on a
held-out seed in this revision (Section 5.14 sweeps it and shows the objective
cannot select it without truth).

## Reproducing

To run one stage:

```bash
cd src && python3 run_experiments.py <stage> [args]
```

To run the entire suite from the repository root:

```bash
python3 -m reproduce_all --fast    # 8 analytic/audit stages, ~4.5 min, no simulation
python3 -m reproduce_all --fast --tol 1e-12   # the same tier as CI runs it: exact
                                   # equality is a property of one BLAS, not a result
python3 -m reproduce_all --full    # 70 stage invocations, 10-seed ensembles (hours)
python3 -m reproduce_all --stages "quadrature clouds 3"    # selected stages
python3 -m reproduce_all --fast --ext    # plus the 14 extension modules
python3 -m reproduce_all --make-baseline tools/baseline_manifest.json
python3 -m reproduce_all --check   # byte-level drift check against that baseline
```

Both tiers copy `results/` to a scratch tree and re-run through
`SGL_RESULTS_DIR`, so the shipped archives are never written by a verification
run; each prints a diff report and exits non-zero on any mismatch.

Verification:

```bash
pytest tests -q -m "not slow"      # fast gates: units, archives, cross-consistency
pytest tests -q -m slow            # re-solves the fiducial pipeline: ~2.5 min
#   with results/cache/ present, hours on a fresh clone (the cache is not shipped)
bash tools/verify_flat.sh          # gates G-1..G-7 (single-version consolidation)
bash tools/verify_flat.sh --full   # also npm build and the numeric gate G-3
bash tools/check_pdf_build.sh      # rebuild both PDFs from scratch and compare
                                   # them with the shipped ones (CI's paper job)
bash tools/run_ext_full.sh         # regenerate every extension archive at full tier
```

`.github/workflows/verify.yml` runs the fast tier of all three, plus that LaTeX
rebuild, on every push.

### Proof layers

The gates above answer "did the pipeline change?".  Four more tools answer the
questions a manuscript actually has to answer, in the order a build would run
them -- reduce, vouch, check the document, check the prose about the document:

```bash
bash tools/verify_numbers.sh          # all of the below, in one command
```

| Tool | Question it answers | What the tree currently says |
| --- | --- | --- |
| `tools/derive_stats.py` | Which numbers does the paper derive from archives rather than read off them? | 1033 statistics in 6 families, in `tools/derived_stats.json` |
| `tools/claims.py` | Can every printed number be traced to an archived value, or to arithmetic over one? | 654 ledger entries, of which 629 are harvested claims and 25 are prose arithmetic re-evaluated from archived inputs; 2224 printed numbers examined, 0 unexplained |
| `tools/manuscript_outline.py` | Is the document the shape its own abstract claims, in the order it claims? | 36 pages, 9 figures, 16 tables, 28 references, 18 numbered equations, 4 appendices, 0 findings |
| `tools/doc_numbers.py` | Do the README, the test documentation, Appendix D and CI still state the same counts as the tree? | 33 documented claims, 58 numbers, 17 module rows, 0 findings |

`tools/claims.py --check` is the strict one: a decimal printed in the manuscript
either resolves to a path in `tools/derived_stats.json` or to a relation this tool
evaluates itself, and an unresolvable number is an error.
`tools/manuscript_outline.py` reads `main.aux` and `main.log` when a build has
just happened, and falls back to the tracked `tools/manuscript_build_record.json`
in a checkout with no TeX; its structure fingerprint is what stops a page number
left over from an earlier skeleton being used to prove this one is in order.
`tools/doc_numbers.py` re-measures the suite, the archives and the driver rather
than trusting any of them to be written down correctly, which is how a stale
`207 test functions` in a README becomes a failed gate instead of a fact nobody
checks.

## Compiling the paper

```bash
cd paper && pdflatex main.tex && pdflatex main.tex
```

Requires a standard TeX Live with `natbib`, `booktabs`, `fancyhdr`,
`mathptmx`, `hyperref` (no AASTeX/revtex needed), plus the Times metric
fonts of `texlive-fonts-recommended`.

`paper/main.tex` is the single source of truth. If the journal needs an
AASTeX port, it should be generated from `main.tex`. See `docs/HISTORY.md`
for the provenance of the earlier AASTeX draft.

## Physical conventions

Fiducial case follows the published SGL literature: exo-Earth at
z₀ = 30 pc observed from z = 650 AU, d = 1 m, λ = 1 μm;
Q_exo = 8.01×10⁴ s⁻¹, Q_cor = 6.20×10⁹ s⁻¹ (Turyshev & Toth 2022,
MNRAS 515, 6122); aperture-averaged kernel K(ρ) = d/4ρ normalized to
unit mean disk signal (Turyshev 2026, arXiv:2606.14899). The code
reproduces SNR_C = 43.16 per 1800 s dwell and the 0.891·D/(d√N)
deconvolution penalty as validation gates.

No real observational data are used; all inputs are seeded synthetic
scenes plus published constants.
