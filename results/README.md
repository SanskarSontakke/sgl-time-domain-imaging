## Subdirectories

- `parts/` — 582 unprefixed per-configuration checkpoints written by individual runs. Each checkpoint is named by its configuration (e.g. `clouds_f3_s11.npz` for fc=0.55, seed 11). The `merge` command consolidates these into the top-level archives above.
- `cache/` — 5 memoised operators and datasets (forward operators `dat_*.npz`, `F_*.npy`, `LtL_*.npy`, and `sigma_cl.json`). These are rebuilt by `setup` and reused across runs to avoid recomputing the 0.68 GB float32 forward operator.

## Synthetic-input data dictionary

- **Truth albedo map** — seeded (7) multi-octave Gaussian fields, 72 x 144 lon-lat grid (truth/field grid); ocean 0.06, land 0.32±0.10, polar caps ≤0.60, land fraction 0.30. Analysis grid is 36 x 72.
- **Cloud field** — advected Ornstein–Uhlenbeck opacity screen; correlation length 12°, advection 6°/day, τ_c = 4 d, cloud albedo 0.65; mean cover set by a fixed calibrated threshold.

## Baseline naming

The approximate-deflation baseline is named `deflate` throughout the code and archives. This was previously labelled differently in earlier repository versions; the rename is documented in `docs/HISTORY.md` and was performed by `tools/flatten_archives.py`.

## The `reldev_F_vs_C` array

The `component_ablation.npz` archive contains `reldev_F_vs_C`, which is ||F − C|| / ||F||: the per-seed relative deviation of the full-TDI map (F) from the approximate-deflation baseline (C). The earlier name `reldev_F_minus_C` was a misnomer (it suggested an absolute difference rather than a relative one) and has been fixed by `src/run_experiments.py`.
