# src/ — simulation and analysis code

| File | Role |
|------|------|
| `sglsim.py` | Library: SGL kernel & convolution, photon/noise model, rotating+illuminated scene renderer, OU cloud model, campaign/raster definition, forward-operator builder, TDI/GLS estimators, baselines (static Wiener, phase-binned coadd), metrics (SSIM/r/NRMSE). |
| `run_experiments.py` | CLI driver for the revised suite. Every command loops its seeds *inside one process* so the 0.68 GB float32 forward operator is built once, and every per-seed result is checkpointed to `results/parts/v3_*.npz`; `merge` then assembles the shipped `results/*.npz` archives and writes `results/audit.json`, which records for each headline number how many seeds actually produced it. The `v3_` part prefix is deliberate: the v2 parts share the bare names, and an unprefixed checkpoint would let superseded numbers satisfy a skip-if-done test. Subcommands: `setup`, `quadrature`, `ledger`, `validation`, `clouds <i_fc>`, `cadence <arm> <i_cfg>`, `cadence_control <arm> <i_cfg> <cf\|iid>`, `components`, `robust_debias`, `robust_clim`, `robust_geom`, `robust_prof`, `resolution`, `nulls_cloud`, `nulls`, `systematics`, `lam_sweep <i_fc>`, `lam_ext <i_fc>`, `lam_res <i_fc>`, `robust_weather <variant>`, `robust_morph <i_fc>`, `sigma_sens`, `sigma_sens_est`, `latband`, `static_ref`, `diagnostics`, `precision`, `merge`. |
| `expcommon.py` | Single source of the experiment conventions (seeds, quadrature order, cloud fractions, campaign arms, cache keys, `sigma_cl` calibration cache, paired statistics, part-file checkpointing). Nothing outside this file chooses a seed or a cadence. |
| `targets.py` | Computes the target-selection table (image sizes, photon rates, focal-line antipodes, ecliptic latitudes, image-plane dynamics, tracking budgets) → `results/targets.json`, `paper/figures/fig_targets.pdf`, `paper/targets_table.tex`. The sixth row ($\tau$~Cet~e) is flagged in both the table footnote and the figure as a *refuted* RV signal kept only as a dynamics illustration. |
| `make_figures.py` | Renders Figures 1–8 from `results/*.npz` into `paper/figures/` (Figure 7, `fig7_lambda_sigma`, is the regularization/$\sigma_{\rm cl}$ sensitivity panel; Figure 8 is the target map from `targets.py`). Optional args select figures, e.g. `python3 make_figures.py 3 5`. |
| `make_app_maps.py` | Re-renders the demo map payload from `results/clouds.npz` (seed 11, fiducial campaign) into `data/reconstructionMaps.ts` + `public/data/reconstruction_maps.json`, using the same cividis [0, 0.7] window as the paper figures. |
| `make_app_data.py` | Rebuilds the downloadable `public/data/project_data.json` blob from `results/audit.json` + `results/clouds.npz` + the standalone JSON artifacts, so the site's machine-readable file cannot keep stale v2 numbers. The per-fc means, ddof=1 SEs and per-method detection d' all come from the archived per-seed matrices. |
| `make_app_code.py` | Rebuilds `data/codeSnippets.json` -- the text the demo "Source Code" viewer displays -- by reading the live `src/` files verbatim, so that panel cannot show code the archive was not produced by. |
| `make_app_figures.py` | Mirrors `paper/figures/*.pdf` into `public/figures/` and rasterises a 200 dpi PNG of each (`pdftoppm`), so the demo figure gallery cannot show a figure that differs from the manuscript. Run after `make_figures.py` and `targets.py`. |
| `v2_superseded/` | Pre-revision scripts, kept for the audit trail only and no longer runnable against this `sglsim.py` (see the README there). The v2 *checkpoint* files moved to `results/parts/v2_superseded/` for the same reason. |

Conventions: normalized scene units (1 = disk-mean signal of a fully
illuminated albedo-0.3 planet); all constants at the top of `sglsim.py`
with citations; every stochastic element takes an explicit seed.
